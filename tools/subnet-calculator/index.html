What is a subnet calculator?

A subnet calculator divides an IPv4 network into address ranges and shows the values engineers need for network planning, firewall rules, routing and infrastructure documentation.

Common CIDR examples

  • /24 — 256 total addresses
  • /16 — 65,536 total addresses
  • /30 — 4 total addresses
  • /32 — a single IPv4 address
