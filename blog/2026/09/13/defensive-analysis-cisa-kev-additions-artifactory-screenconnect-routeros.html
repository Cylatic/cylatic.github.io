Defensive Analysis of Recent Additions to CISA KEV: Artifactory, ScreenConnect, and RouterOS Exploitations

A rigorous technical evaluation of five actively exploited vulnerabilities added to the CISA Known Exploited Vulnerabilities catalog, covering detection engineering, telemetry requirements, and architectural hardening.

13 Sep 2026THREAT INTELLIGENCE7 minutesCISA KEV · ARTIFACTORY · SCREENCONNECT · ROUTEROS
← Back to Research

Recent updates to the Cybersecurity and Infrastructure Security Agency (CISA) Known Exploited Vulnerabilities (KEV) catalog have incorporated five actively exploited flaws impacting JFrog Artifactory, ConnectWise ScreenConnect, and MikroTik RouterOS platforms. For security operations centers (SOCs), threat-hunting teams, and infrastructure engineers, these additions signify an urgent transition from passive vulnerability awareness to active remediation and heuristic monitoring. This analysis explores the technical attack surface, telemetry requirements, SIEM correlation strategies, and architectural imperatives necessary to protect enterprise environments against weaponization of these vectors.

Integrating these updates into routine prioritization models is critical. Because exploitation in the wild has been confirmed by authorities, environments hosting these assets face elevated risk profiles. Security teams must evaluate not only patch levels but also runtime telemetry and boundary defenses to identify post-exploitation activities or initial intrusion attempts.

Technical Significance and Attack Surface

The inclusion of Artifactory, ScreenConnect, and RouterOS vulnerabilities highlights a diverse attack surface spanning enterprise artifact repositories, remote management gateways, and core network routing infrastructure. Each of these components occupies a high-privilege or high-visibility position within enterprise topologies.

  • JFrog Artifactory: Serving as a centralized repository for binary packages, build artifacts, and software dependencies, Artifactory is a cornerstone of modern software supply chains. Compromise of this component can lead to unauthorized code injection, repository tampering, or credential harvesting from connected build pipelines.
  • ConnectWise ScreenConnect: Designed for remote desktop administration and support, ScreenConnect gateways maintain persistent listening ports and facilitate high-privilege interactive sessions. Vulnerabilities in this software provide threat actors with direct pathways to endpoints within internal networks, effectively bypassing traditional perimeter controls.
  • MikroTik RouterOS: Operating at the network edge, RouterOS devices manage routing tables, virtual private network (VPN) terminations, and firewall policies. Flaws in RouterOS threaten the foundational integrity of network transit, enabling man-in-the-middle operations, traffic redirection, or pivoting deeper into the internal enterprise network.

The convergence of these technologies on the KEV catalog demonstrates that adversaries are targeting both internal software delivery mechanisms and external perimeter access points to achieve operational persistence and lateral movement.

Attack Chain and Telemetry Requirements

While specific technical exploit payloads vary across these disparate products, the general attack chain involves perimeter reconnaissance, exploitation of unpatched software interfaces, execution of malicious commands or code with elevated privileges, and establishment of persistent access or data exfiltration.

Defenders must collect and analyze multi-layered telemetry to capture indicators across this chain:

  • Network Telemetry: Capture perimeter firewall logs, NetFlow/IPFIX data, and deep packet inspection (DPI) streams focusing on anomalous inbound connections to ScreenConnect ports and administrative interfaces on RouterOS devices.
  • Endpoint Telemetry: Monitor process execution lineages originating from web server or management daemons on Artifactory and ScreenConnect hosts. Spawning of shell interpreters (e.g., bash, cmd.exe, powershell.exe) from these processes is a high-fidelity indicator of compromise.
  • Application Logs: Audit authentication attempts, administrative session creations, and repository modification logs within Artifactory and ScreenConnect application event logs.

SIEM Correlation and Detection Engineering

To detect potential exploitation attempts and post-exploitation activities associated with these KEV entries, security engineering teams must deploy targeted correlation rules within their SIEM platforms. Detection strategies should focus on anomalous process execution, unexpected administrative activities, and network connection irregularities.

Below is an example Sigma-compatible detection rule designed to identify suspicious child process generation from remote management or repository services:

title: Suspicious Child Process Spawned by Service Daemons
id: a1b2c3d4-e5f6-7890-abcd-ef1234567890
status: experimental
description: Detects web or management daemons spawning command-line shells, indicating potential remote code execution.
references:
  - https://www.cisa.gov/known-exploited-vulnerabilities-catalog
author: Cylatic Threat Intelligence
date: 2026/09/13
tags:
  - attack.execution
  - attack.t1203
logsource:
  category: process_creation
  product: windows
detection:
  selection_parent:
    ParentImage|endswith:
      - '\ScreenConnect.Service.exe'
      - '\artifactory.exe'
  selection_child:
    Image|endswith:
      - '\cmd.exe'
      - '\powershell.exe'
      - '\sh'
      - '\bash'
  condition: selection_parent and selection_child
falsepositives:
  - Legitimate administrative maintenance scripts running during scheduled update windows.
level: high

SOC analysts should correlate alerts generated by this rule with upstream web proxy logs, authentication success metrics, and subsequent outbound network connections to ensure comprehensive incident triage.

Threat-Hunting Methodologies

Proactive threat hunting in environments utilizing Artifactory, ScreenConnect, or RouterOS should center on historical log analysis and artifact verification. Because these additions represent actively exploited vulnerabilities, hunting queries should look back across the maximum available retention window.

  • Artifactory Environments: Search for unexpected modifications to system configurations, newly created user accounts with administrative privileges, and unauthorized file writes to sensitive installation directories.
  • ScreenConnect Gateways: Review active extension installations, inspect connection logs for sessions originating from unfamiliar geographic regions or IP ranges, and verify the integrity of application binaries.
  • RouterOS Devices: Audit firewall rule configurations, inspect running scripts and scheduled tasks for unauthorized entries, and check for unexpected user account additions or SSH key modifications.

What defenders should do now

Organizations operating any of the affected software packages must execute immediate remediation and hardening protocols to mitigate active exploitation risks.

  1. Prioritize Patching: Immediately apply vendor-supplied security updates for JFrog Artifactory, ConnectWise ScreenConnect, and MikroTik RouterOS in accordance with the CISA KEV remediation timeline.
  2. Isolate Management Interfaces: Ensure that administrative panels and management ports for ScreenConnect and RouterOS are not exposed directly to the public internet; restrict access to trusted internal jump hosts or secure VPN tunnels.
  3. Verify Endpoint Telemetry: Confirm that EDR agents or advanced logging tools are actively monitoring the hosts running these applications, ensuring visibility into child process generation and file system modifications.
  4. Review Network Access Controls: Implement strict egress and ingress filtering around artifact repositories and edge routing devices to limit potential lateral movement or data exfiltration channels.

Hardening and Architecture Implications

From an architectural standpoint, the exploitation of edge devices and internal repositories reinforces the need for zero-trust principles. Network segmentation must be enforced to isolate management planes from standard user traffic. Furthermore, software supply chain components like Artifactory require rigorous access controls, multi-factor authentication for administrative functions, and continuous integrity monitoring.

By treating these KEV catalog additions not merely as items on a patch checklist, but as active indicators of adversary focus areas, security teams can significantly improve their operational posture and resilience against sophisticated threat campaigns.
